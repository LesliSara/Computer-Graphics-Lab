### Practice: Hierarchical Models

#### Objective
In this practice, we implemented hierarchical modeling to construct a **3D crane** and a **robotic animal**. The goal was to develop articulated structures using geometric primitives and enable interaction through keyboard controls.

<h2>Implementation Details</h2>

### 🚜 3D Crane Construction
- **Preliminary Work**
  - The arm, joints, and operator’s cabin were previously modeled.
- **Final Model Components**
  - **Body**: A rectangular prism representing the main structure.
  - **Base**: A square pyramid supporting the crane.
  - **Wheels**: Four cylinders, each individually rotatable using the keyboard.

### 🤖 3D Robotic Animal
- **Structure**
  - Built using **cubes, pyramids, cylinders, cones, and spheres**.
- **Articulated Parts**
  - **Legs**: Four legs, each with two articulated segments (controllable via keyboard).
  - **Tail or Ears**: Either a movable tail or two independently articulated ears.

### 🎮 Interaction & Controls
- The keyboard allows real-time manipulation of:
  - Each wheel of the crane.
  - The two joints of each leg.
  - The tail or ears of the robotic animal.

This project showcases hierarchical modeling principles and real-time interaction, enhancing understanding of 3D transformations in computer graphics.
